# iamtalkernote 안드로이드

> **짝이 되는 저장소 — 개발할 때는 둘 다 읽으세요.** 데스크톱 앱 [iamtalkernote](https://github.com/iamtalker/iamtalkernote)(로컬 `C:\MyData\claude program\1. 개발중\iamtalkernote`, 이 폴더의 `..\iamtalkernote`)의 README 에 있는 "이어서 작업하기"와 로드맵을 함께 보세요. 두 앱은 같은 노트 폴더의 파일 형식(머리말, `태그:` 줄, `.history/`, `.trash/`, `.resources/`, `.imported/docs.jsonl`)을 공유하므로 한쪽을 바꾸면 다른 쪽도 확인해야 합니다.

[iamtalkernote](https://github.com/iamtalker/iamtalkernote)(윈도 노트·문서 앱)의 안드로이드 짝입니다. 컴퓨터의 iamtalkernote 와 **같은 노트 폴더(마크다운 파일)** 를 폰에서 읽고 고치는 앱입니다. 현재 **1.2.0** 입니다. **개발 PC 에서 기기나 에뮬레이터로 실행해 보지 못하고**(빌드와 순수 로직 시험만) 사용자가 폰에서 써 보며 알려 준 문제를 고쳐 왔습니다.

## 설치
[Releases](https://github.com/iamtalker/iamtalkernote-android/releases) 의 `iamtalkernote-android.apk` 를 폰에 받아 설치합니다(출처를 알 수 없는 앱 설치 허용 필요). 디버그 서명이라 스토어 업데이트는 없고, 새 버전은 같은 방법으로 덮어 설치합니다.

## 지금 되는 것 (1.3.1)
조플린·업노트 안드로이드 앱의 구성을 참고했습니다.
- **업노트 구성의 화면** — 밝은 상단바와 가운데 파란 제목, 위쪽에 접히는 *고정됨* 구역, 아래 3칸 바(노트북·검색·⋯)와 연필 버튼, ⋯ 메뉴(새 노트북·노트 필터·노트 정렬·노트 선택·설정). 서랍은 모든 노트 → 미분류 → 색 노트북(접기) → 태그 → 가져온 파일 → 휴지통·설정 순서. 어두운 테마 지원, 새 앱 아이콘.
- **설정 화면** — 동기화·테마·일반(자동 새로고침, 폴더 다시 고르기)·에디터(바로 편집, 글자 크기)·도구(휴지통·이력·충돌·중복·안 쓰는 미디어)·정보.
- **동기화 연결 마법사**(설정 → 동기화) — 폰의 Syncthing-Fork 를 이 앱이 대신 설정합니다. Fork 의 API 키와 컴퓨터 기기 ID 를 붙여넣고 *컴퓨터 추가*를 누르면, 컴퓨터가 허용한 뒤 보내는 공유 폴더를 노트 폴더 아래 알맞은 경로(노트·`.resources`·`.imported`·`.history`·`.trash`·노트북, 외부 폴더는 `<노트폴더>-files/`)로 자동 수락하고, `.sync/policy.json` 이 도착하면 방향(양방향·받기 전용·보내기 전용)을 맞춥니다. Fork 의 로컬 API(`https://127.0.0.1:8384`, 자체 서명 인증서 — 루프백에서만 검사를 끔)를 쓰므로 INTERNET 권한이 있습니다. 코드는 `ForkSync.kt`·`SyncWizard.kt`.
- **태그 규칙을 데스크톱과 같게(1.3.1)** — 본문 `#태그`는 코드·주소·그림 속, `( [ / = - . : ? & #` 바로 뒤, 숫자로 시작하는 이름이 아니면 태그입니다(위키 각주 `](#cite_note-…)` 가 태그로 잡히던 문제 수정). 이름 바꾸기·삭제도 같은 규칙으로 찾은 자리만 고칩니다. 코드는 `HashTags.kt`(데스크톱 `notes.py` 의 `hashtags`·`mask_protected`·`line_tags` 와 같은 입력에서 같은 결과를 내는지 `HashTagsTest` 로 확인). 규칙이 바뀌어 처음 실행 때 노트 색인을 한 번 다시 만듭니다.
- **Syncthing-Fork 찾기(1.3.1)** — Fork 는 배포처마다 패키지 이름이 달라(`…syncthingandroid` 플레이·F-Droid, `…syncthingfork` GitHub 최신판, 공식 앱) 모두 찾고, API 키가 통하면 설치된 것으로 칩니다. 설치 버튼은 구글 플레이 → 플레이 웹 → F-Droid → GitHub 순서로 엽니다.
- **볼트 폴더 구조 자동 준비** — 노트 폴더를 고르거나 앱을 열 때 `.history` `.trash` `.resources` `.imported` `.sync` 가 없으면 만듭니다(있는 폴더·노트는 건드리지 않음). 동기화 도구(Syncthing-Fork)에서 폴더 경로를 고를 때 이 폴더들이 이미 있어 편합니다.
- **서랍(왼쪽 위 가로줄 세 개, 또는 화면 왼쪽 가장자리에서 밀기)** — 모든 노트 / 가져온 파일 / 저장된 검색 / 노트북 트리(개수) / 태그(개수) / **도구**(휴지통·전체 변경 이력·동기화 충돌·중복 노트·안 쓰는 미디어·새로고침·다른 폴더 고르기). 고르면 목록이 그 범위로 좁혀집니다. 서랍·메뉴 아이콘은 글자가 아니라 직접 그린 그림입니다(폰 글꼴에 ☰ ⋮ 가 없으면 안 보이는 문제가 있었습니다).
- **카드 목록** — 제목, 본문 미리보기 두 줄, 날짜·노트북·태그. 노트 안 ⋮ 메뉴에서 *맨 위에 고정*(★)하면 목록 맨 위에 둡니다(고정은 이 폰에만 저장).
- **검색** — 공백 = AND, `"구절"`, `-제외` 또는 `NOT 낱말`, `#태그`. *본문까지* 체크로 제목만/본문 포함. 정렬은 오른쪽 위 *정렬*(최근/오래된/제목).
- **마크다운 보기** — 제목·목록·**체크박스(눌러서 켜고 끄면 바로 저장)**·인용·코드·표(글자 그대로)·굵게/기울임/링크, **그림**(`../.resources/…` 상대 경로로 찾아 보여 줍니다. 인터넷 그림은 아직 안 보임). 노트를 열면 보기, *편집* 으로 고칩니다.
- **노트 하나에 하는 일(⋮)** — 공유, 이름 바꾸기, 노트북으로 이동(그림 링크의 `../` 개수를 데스크톱처럼 맞춤), **휴지통으로**(데스크톱과 같은 `.trash/<번호>/item + meta.json` 형식이라 컴퓨터 앱의 휴지통에서 복원됩니다. 폴더에서 옮기기를 지원하지 않으면 지우지 않고 이유를 알려 줍니다).
- **머리말 읽기**(`updated`, `tags`, `#태그`, `태그:` 줄), **색인 DB**(처음 한 번 색인, 이후 바뀐 노트만), 폰 설정에 따른 **다크 모드**.
- **쓰기(0.4.0)** — 입력을 멈추고 0.6초 뒤 자동 저장(머리말에 `updated` 가 있으면 지금 시각으로), 편집 중 키보드 위 **서식 도구줄**, ⋮ 메뉴의 **문서에서 찾기**·**태그 편집**(글 맨 아래 `태그: #a #b` 줄)·**속성**, 본문 `[[노트 제목]]` 링크(누르면 그 노트로).
- **안전망(0.5.0)** — 고칠 때마다 이전 내용을 노트 버전으로 남기고(노트를 연 뒤 처음 고칠 때는 꼭, 그 뒤로는 1분 간격, 10개까지) ⋮ → *이전 버전*에서 보고 되돌립니다. 노트 이름을 바꾸거나 옮기면 버전 기록도 따라갑니다. 서랍 *도구*의 **휴지통**(복원은 원래 노트북으로, 같은 이름이 있으면 ‘(복원)’)과 **전체 변경 이력**.
- **찾기(0.6.0)** — `회의록 AND (예산 OR 일정) NOT 취소`, `"구절"`, `#태그`, `-제외`. 검색창에 글자를 치면 아래에 제목·태그 후보가, 비어 있으면 최근 검색이 뜹니다. 오른쪽 위 *정렬* 메뉴에서 정렬·기간·*지금 검색 저장*, 서랍의 *저장된 검색*에서 불러옵니다. 카드를 길게 누르면 여러 개를 골라(전체 선택 가능) 한꺼번에 이동·태그 추가·휴지통으로 보냅니다.
- **들이기(0.7.0)** — 브라우저·다른 앱의 *공유*로 글/주소를 받아 노트북을 골라 저장, 편집 중 *그림* 버튼, 서랍에서 태그 이름 바꾸기·삭제.
- **정리(0.8.0)** — 서랍 *도구*의 *중복 노트 찾기*·*안 쓰는 미디어*, 앱 밖 수정 감지.
- **동기화 충돌(0.9.0)** — 충돌 복사본을 알아채서 해결 화면으로.
- **가져온 파일(1.0.0)** — 서랍의 *가져온 파일*(컴퓨터 폴더별), 같은 검색식으로 찾고 글 앞부분·태그·메모를 읽기 전용으로 봅니다. 컴퓨터의 iamtalkernote **0.4.2 이상**이 노트 폴더에 내보낸 `.imported` 가 필요합니다.
- **노트북(1.1.0)** — 서랍의 *+ 새 노트북*(위치를 고를 수 있음), 노트북 옆 점 세 개로 *통째로 휴지통으로*(데스크톱에서 복원). 노트가 없는 빈 노트북도 서랍에 보입니다. 이름 바꾸기는 아직 없습니다(폴더 이름이 바뀌면 안의 노트 주소가 모두 바뀌어 색인과 버전 기록이 끊어집니다).
- 죽으면 다음 실행 때 오류 내용을 화면에 보여 줍니다.

## 아직 없는 것 · 알려진 한계
- 노트북 **이름 바꾸기** — 안드로이드는 폴더 이름을 바꾸면 안의 모든 노트 주소가 바뀌어 색인과 버전 기록이 끊어집니다. 이름을 바꾼 뒤 색인을 다시 만드는 방식으로 넣을 수 있습니다.
- 폰에서 **가져온 파일의 태그·메모 고치기** — 지금은 읽기 전용입니다. 폰이 쓴 것을 데스크톱이 합치는 방식(예: 폰이 `.imported/annot-phone.jsonl` 에 덧붙이고 데스크톱이 읽음)이 필요합니다. 원본 파일 열기도 없습니다.
- **데스크톱 쪽 충돌 해결 화면** — 데스크톱 앱은 아직 `…sync-conflict-…md` 를 일반 노트로 보여 줍니다.
- 인터넷 그림(`http`)은 노트에서 안 보이고, 노트 안 찾기는 편집 모드에서만 됩니다. 표는 글자 그대로 보입니다.
- **폰에서 직접 확인하지 못한 기능이 많습니다**(휴지통으로 옮기기·이동·이름 바꾸기는 저장소 제공자가 파일 옮기기를 지원해야 하고, 지원하지 않으면 노트를 건드리지 않고 이유를 알려 줍니다). 에뮬레이터를 쓸 수 있게 되면(아래) 한 번 훑으며 점검하는 것이 먼저입니다.

## 데스크톱 → 안드로이드 이식 로드맵
데스크톱 iamtalkernote 의 기능을 폰에 맞게 옮기는 계획입니다. **데스크톱과 같은 파일 형식을 그대로 써서**(머리말, `태그:` 줄, `.history/`, `.trash/`, `.resources/`) 두 앱이 같은 폴더를 오가도 서로 깨지지 않는 것이 원칙입니다. 단계마다 버전을 올려 릴리스합니다.

- [x] **1단계 (0.4.0) 쓰기 완성** — 자동 저장(0.6초)과 저장 때 머리말 `updated` 갱신, 서식 도구줄(굵게·기울임·취소선·코드·제목·목록·체크·인용·링크·`[[노트]]`), 노트 안 찾기, 노트 속성(위치·파일·갱신/생성·주소·태그·크기), 태그 편집(`태그:` 줄), 노트 링크 `[[제목]]`. (새 노트 머리말은 데스크톱도 머리말 없이 만들어서 뺐습니다.)
- [x] **2단계 (0.5.0) 안전망** — 노트 버전(`.history/<해시>/<밀리초>.md`, 데스크톱과 같은 폴더 이름이라 두 앱이 같은 버전을 봅니다) 보기·되돌리기, 휴지통 화면(`.trash` 보기·복원·완전 삭제·30일 지난 것 정리·비우기), 변경 이력(`.history/journal.jsonl`에 같은 형식으로 적고 보기).
- [x] **3단계 (0.6.0) 찾기 고도화** — 검색식 OR·괄호·`NOT`·`& | !`(데스크톱과 같은 문법), 정렬(관련도·수정·생성·제목)과 기간 필터(오늘·7일·30일·1년), 자동완성(제목·`#태그`)과 최근 검색 30개, 저장된 검색(이 폰에만 저장), 여러 노트 선택(카드를 길게 눌러 → 이동·태그 추가·휴지통). 관련도는 데스크톱처럼 본문 밀도가 아니라 제목·미리보기 글에 낱말이 있는지로 매깁니다.
- [x] **4단계 (0.7.0) 들이기** — 다른 앱에서 *공유 → iamtalkernote*로 받아 새 노트(주소는 머리말 `source`에), 편집 중 *그림* 버튼으로 사진·그림 첨부(`.resources`에 복사하고 상대 경로로 연결), 태그 관리(서랍의 태그 ⋮ → 이름 바꾸기·합치기·삭제: 머리말 tags·`태그:` 줄·본문 `#태그` 세 군데를 모두 고치고 이전 내용은 노트 버전으로).
- [x] **5단계 (0.8.0) 정리 도구** — 중복 노트 찾기(제목이 같고 번호는 무시, 본문이 완전히 같은 것만; 최근 것만 남기고 휴지통), 안 쓰는 미디어 찾기·삭제(휴지통 속 노트의 링크까지 확인, 폰에서는 휴지통 없이 바로 삭제), 앱 밖 수정 감지(동기화 도구 등이 고친 노트를 다음 새로고침 때 알아채서 변경 이력에 *앱 밖 수정*으로 적고 고친 뒤의 내용을 노트 버전으로 남김).
  - **폰에서 하지 않는 것**: *스크랩 군더더기 정리*(사이트 통계를 내려고 노트 전체를 읽는 무거운 작업이라 컴퓨터에서), *복원 지점*(노트 전체의 해시 목록을 만들고 모든 변경 앞에서 보관해야 해서 컴퓨터 전용 — 폰은 노트 버전과 휴지통으로 되돌립니다).
- [x] **7단계 (0.9.0) 동기화 충돌 처리** — Syncthing 의 `이름.sync-conflict-날짜-시각-ID.md` 복사본을 목록에서 빼고 *동기화 충돌*(목록 위 띠·메뉴)에 모아, 원래 노트와 비교해 *내 것 / 상대 것 / 둘 다 / 원래 이름으로* 를 고릅니다. 지는 쪽 내용은 노트 버전(또는 휴지통)에 남습니다.
- [x] **6단계 (1.0) 가져온 파일** — 데스크톱 0.4.2 가 가져온 문서의 이름·폴더·태그·메모·글 앞부분(2만 자)을 `.imported/docs.jsonl` 로 내보내고, 폰이 그것을 읽어 서랍의 *가져온 파일*에서 목록·검색(이름·경로·태그·메모, 본문까지 선택)·보기(읽기 전용)로 보여 줍니다. 원본 파일은 폰에 없습니다(원하면 그 폴더를 따로 동기화).
  - 남은 일: 폰에서 가져온 파일의 태그·메모 고치기(폰이 쓴 것을 데스크톱이 합치는 방식이 필요), 원본 열기.

**옮기지 않는 것**: 트레이·한 번에 하나만 실행·창 상태·칸 너비(폰에 해당 없음), 윈도 미리보기·Edge 재생 창, 웹 클리퍼 서버(폰은 *공유*로 대체), 문법 해설 사이드바(서식 도구줄로 대체), 테마 여러 가지(폰의 라이트/다크를 따름), 스캔 PDF OCR.

## 개발 환경 로드맵
- [ ] **PC 가상화 켜기 → 에뮬레이터** — 지금은 BIOS 에서 가상화(AMD SVM Mode)가 꺼져 있어 에뮬레이터를 쓸 수 없고, 폰에 직접 설치해서만 시험합니다. 켠 뒤에는 Windows 하이퍼바이저 플랫폼을 켜고 SDK 에뮬레이터(시스템 이미지)를 설치해, 로그(`adb logcat`)와 화면을 보면서 개발합니다.

## 동기화에 대한 생각
- 파일 전송은 **폴더 동기화 도구(예: Syncthing)** 에 맡기고, 앱은 같은 폴더를 읽고 씁니다. 그래서 자체 서버가 필요 없고, 노트 파일이 원본이라는 원칙이 그대로입니다.
- 양쪽에서 같은 노트를 고치면 Syncthing 이 `…sync-conflict-…md` 같은 이름의 복사본을 남깁니다. 앱이 이런 파일을 알아채서 *충돌* 로 보여 주고 노트 버전으로 합치게 하는 것이 다음 큰 일입니다(데스크톱의 *앱 밖 수정 감지* 가 그 안전망).
- 용량: 폰에는 폴더 전체가 아니라 **고른 노트북만** 받는 편이 현실적입니다(Syncthing 의 폴더·무시 규칙으로 가능).

## 빌드
JDK 17 + Android SDK(34)가 필요합니다. 한글 경로에서도 빌드되도록 `gradle.properties` 에 `android.overridePathCheck=true` 를 켜 두었습니다.

```
cd iamtalkernote-android
./gradlew assembleDebug        # → app/build/outputs/apk/debug/app-debug.apk
```

단위 시험(`./gradlew testDebugUnitTest`)은 한글 경로에서는 클래스를 못 찾으니 영문 경로 사본에서 돌립니다.

`local.properties` 의 `sdk.dir` 은 사용자마다 달라서 저장소에 없습니다(환경 변수 `ANDROID_HOME` 도 됩니다).
